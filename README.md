# Closet AI — sitio público

Las páginas que App Store Connect exige para publicar la app: soporte, política de privacidad y
página de producto, en español, inglés y francés.

    /                      es · producto
    /soporte.html          es · soporte
    /privacidad.html       es · privacidad
    /en/  /en/support.html  /en/privacy.html
    /fr/  /fr/support.html  /fr/confidentialite.html

La política describe lo que la app hace **de verdad**, contrastado con el código: qué se queda en el
iPhone, qué se envía al servicio con el acabado de estudio, y qué se guarda para las cuotas. Si el
comportamiento de la app cambia, esta política cambia con él.
